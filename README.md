# Лабораторная работа №2 — Параллельное программирование

**Тема:** Исследование масштабируемости параллельного умножения матриц с использованием OpenMP  
**Студент:** Влас Янкин  
**Год:** 2026

## Описание

Модификация программы из лабораторной работы №1 для исследования масштабируемости. 
Проведена серия экспериментов на матрицах размером от 200 до 2000 с разным количеством потоков OpenMP.

## Структура проекта

- `cpp/` — исходный код C++ (последовательная и OpenMP версии)
- `python/` — скрипты генерации, верификации и запуска бенчмарков
- `plot.py` — скрипт построения графиков
- `REPORT.md` — полный текст отчёта с результатами и графиками
- `CMakeLists.txt` — файл сборки

## Сборка и запуск

```bash
# Сборка
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build

# Генерация данных
python python/gen_matrices.py 200 400 800 1200 1600 2000

# Бенчмарк
python python/run_benchmarks.py

# Графики
python plot.py
